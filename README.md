# ちゃっと放送局 1.6.3

Delta Chatのグループで、収録音声・短い録画動画・音声LIVE・動画LIVEを配信して、メンバーが聴く・見るためのwebxdcミニアプリです。1.6.3では、PCのブラウザでカメラ・マイクと別タブ間のLIVEを試すプレビューも利用できます。

## はじめに選ぶ使い方

| 使い方 | 開くもの | 共有する相手 |
|---|---|---|
| Delta Chatで使う | `chatto-broadcast-1.6.3.xdc` をグループへ添付 | 同じグループの同じ添付を開くメンバー |
| PCのブラウザでデモを試す | `index.html` をブラウザで直接開く | 同じPC・同じブラウザの別タブ |

**Delta Chatでは、全員がグループ内の同じ添付メッセージから開いてください。** 同じファイル名でも、別々に添付したコピーは別の放送局になります。

**ブラウザプレビューとDelta ChatはLIVEでつながりません。** ブラウザ版はカメラ・マイク・画面操作を試すためのものです。別のPCへ配信する機能はありません。

## ファイルの説明

| ファイル | 使い方 |
|---|---|
| [Delta Chat用アプリ](chatto-broadcast-1.6.3.xdc) | 対象グループへ一度だけ添付します |
| [操作マニュアル HTML](chatto-broadcast.html) | スマートフォン・PCで読む説明書。画面図を内蔵し、オフラインでも閲覧できます |
| [ブラウザ用デモ](index.html) | ChromeやEdgeで直接開いて、画面操作やカメラ・マイクを試します |

マニュアルは全17ページ・画面図14点です。図は操作説明用の模式図で、実際の配置は端末・文字サイズにより異なります。ブラウザプレビューは15・16章で説明しています。

## Delta Chatで放送局を始める

1. 開設する担当者を決めます。
2. 担当者が `chatto-broadcast-1.6.3.xdc` を対象グループへ一度だけ添付します。
3. その添付を開き、「放送局を開設する」を押します。開設した人がオーナーです。
4. メンバー全員に、同じ添付から一度開いてもらいます。
5. オーナーが上部の「管理」を開き、配信する人の「配信者にする」を押します。

| 役割 | できること |
|---|---|
| メンバー | 収録の再生、LIVEの視聴、一言メッセージ、受信完了済み放送の書き出し |
| 配信者 | メンバーの操作に加え、収録・LIVEの配信、自分の収録の削除 |
| オーナー | 配信、配信者の設定、収録の削除、履歴JSONの取り込み |

「解除」が端末に届くと、新規投稿と送信待ち中の投稿を停止します。マイク許可待ち中のLIVEも開始しません。解除前に受信完了した放送は残ります。解除の共有には通信時間が必要です。

## 収録した音声を聴く

1. 一覧で、聴きたいタイトルの「▶」を押します。
2. 同じボタンか画面下の再生ボタンで一時停止します。
3. 途中から聴くときは、画面下の再生位置のつまみを動かします。

「50%」などの表示は受信途中です。受信が完了すると再生できます。収録の再生にはマイクの許可は不要です。

### 同じ放送をリピートする

音声は画面下の再生欄、録画動画は動画再生画面の「この放送をリピート」にチェックを入れます。最後まで進むと、同じ1件の先頭から繰り返します。

チェックを外すと、その回の最後で止まります。すぐ止めるときは一時停止を押します。設定は自分の端末だけに適用され、音声・動画で共通です。別の収録に切り替えても維持しますが、アプリを開き直すとOFFに戻ります。一覧全体の連続再生やLIVEには適用されません。

## 収録した音声を配信する

1. 「配信する」を開き、内容が分かるタイトルを入力します。
2. 丸いボタンで録音を開始し、もう一度押して止めます。マイクを使えない端末では「または音声ファイルを選ぶ」から録音済みファイルを選びます。
3. 試聴して内容を確認し、「配信する」を押します。
4. 送信が終わるまでアプリを画面に表示したまま待ちます。

アプリ内録音は最長3分、音声1件は約3MBまでです。分割送信のため、数分以上かかる場合があります。通常の収録配信には中断後の自動再開がありません。不完全な放送が残ったときは、配信元かオーナーが削除して再配信します。

## 録画動画を配信して見る

1. 「配信する」→「録画動画ファイルを選ぶ」を押します。
2. 60秒以内・約5MB以下の動画を選び、プレビューで映像と音を確認します。
3. タイトルを入力し、「配信する」を押します。
4. メンバーは受信完了後、一覧の「動画」の「▶」で再生します。「閉じる」で一覧へ戻ります。

この操作は撮影済みファイルの選択です。アプリ内でカメラ撮影して録画ファイルを作る機能はありません。撮影・編集・圧縮は別のアプリで行います。動画形式は端末により対応が異なります。MP4でも映像・音声の圧縮形式によって再生できない場合があります。

動画は全データが届いてから再生します。最大容量に近い動画は共有に時間がかかります。まず小さなファイルで試してください。

## 音声LIVEと動画LIVEを使う

1. 配信者が「ライブ」を開き、タイトルと配信の種類を選びます。
2. 音声のみなら「音声LIVE」、映像も送るなら「動画LIVE（実験）」を選びます。
3. 「ライブ開始」を押し、端末が求めるマイク・カメラ利用を許可します。
4. 視聴者は同じ添付を開き、LIVE欄の「▶」を押します。
5. 無音のときは「音声を再開」を押し、音量・出力先・配信元のミュートを確認します。
6. 配信は「終了」、視聴は「停止」で終わります。

動画LIVEは最大320×240・約2コマ／秒の実験機能です。滑らかな動画ではなく、映像と音声のずれやコマ落ちがあります。LIVEの音声・映像は収録として保存されません。利用中は両側とも画面を開いたままにします。

端末とDelta Chat本体の版により、マイク・カメラを利用できる条件が変わります。本体やOSが拒否する機能を、アプリから解除することはできません。ブラウザ用プレビューで成功しても、Delta Chat内での利用を保証するものではありません。

### 配信者へ一言を送る

視聴を始めると「配信者へ一言」が表示されます。1～80文字を入力して「一言を送る」を押します。配信者側には最新30件を表示します。

「配信端末に届きました」は端末から応答があったことを示し、本人が読んだという意味ではありません。連続送信は3秒以上空け、応答待ちは最大約10秒です。到着確認がなくても届いている場合があります。一言はLIVE終了後に保存されず、JSONにも含まれません。通常の個別チャットではありません。

### LIVEが届かないとき

同じ添付から開いていることと、配信者の許可設定を確認します。開始通知とLIVEの音声・映像は別経路です。開始通知だけ届いてもLIVEの接続成功ではありません。

「ライブの接続状況」で、配信側の音声・映像送出と視聴側の受信数が増えるか、実際に再生されるかを確認します。他端末からの受信数には待機通知も含まれます。再接続操作の回数は成功回数ではありません。

回線復旧時と画面へ戻ったときに再接続を試みます。戻らなければ双方で「ライブ通信を再接続」を押し、LIVE欄の「▶」で視聴します。それでも戻らない場合は同じ添付を開き直し、配信者が開始し直します。

## PCのブラウザでプレビューする

### index.htmlを開く

1. `index.html` をダブルクリックするか、ChromeやEdgeの画面へドラッグして開きます。
2. 最初のタブで「放送局を開設する」を押します。
3. 画面操作、音声の録音、録画済みファイルの選択・再生などを試します。

ブラウザや設定によって、カメラ・マイク、保存、別タブ間の共有など、一部の機能を利用できない場合があります。

### カメラとマイクを試す

1. 最初のタブで放送局を開設します。
2. 「ライブ」→「動画LIVE（実験）」→「ライブ開始」でカメラ・マイクを許可します。
3. 配信タブに自分のカメラ映像が表示されます。音声だけを試す場合は「音声LIVE」を選びます。
4. 「別の視聴タブを開く」から視聴タブを開き、LIVE欄の「▶」で視聴します。ブラウザの「タブを複製」ではなく、このリンクを使います。
5. 一言メッセージと到着確認も試せます。ヘッドホンを使うと音の回り込みを避けられます。

### ブラウザプレビューの範囲

- 同じPC・同じブラウザ・同じプロフィールのタブ間だけで共有します。ChromeとEdgeの間、別PC、通常とシークレットウィンドウの間では共有しません。
- Delta ChatとLIVEで接続しません。ブラウザとDelta Chatの収録データは、履歴JSONを書き出し・取り込みして移せます。
- 設定・収録データはブラウザのこのURLの保存領域へ保存します。保存上限があるため、必要な収録はJSONへ書き出してください。サイトデータを削除すると、プレビューの履歴も消えます。
- `index.html` を直接開いた場合の動作はブラウザと設定に依存します。権限の確認が出たら、利用するカメラ・マイクを許可してください。

### 機器を利用できないとき

| 表示されるエラー名 | 確認すること |
|---|---|
| NotAllowedError または SecurityError | ブラウザのサイト設定とWindowsのカメラ・マイク利用許可 |
| NotFoundError | 機器が接続され、利用可能になっているか |
| NotReadableError | 他のアプリが機器を使用していないか、OS側の状態 |

エラー名は原因を絞る手掛かりです。ブラウザやWindowsの拒否設定をアプリが強制解除することはできません。

## 履歴を保存して新しい版へ移る

1. 旧版の「設定」→「放送一覧を書き出す」でJSONを保存します。Delta Chatでは、準備された添付を実際に送信して保存します。ブラウザではダウンロード先を確認します。
2. 新版をグループへ一度だけ添付し、移行先のオーナーが放送局を開設します。
3. 「設定」→「放送一覧を取り込む」でJSONを選び、共有が終わるまで待ちます。
4. 全員が同じ新版の添付を開き、収録の受信完了と再生を確認します。
5. 配信者を改めて設定します。確認が済むまで旧版とJSONを残します。

JSONには受信完了済みの音声・動画本体、タイトル、元の配信者名、日時などが入ります。受信途中・削除済みの放送、配信者の許可設定、LIVE、一言、リピート設定は入りません。同じ履歴の二重取り込みは省略し、移行先で削除済みの放送も復活させません。

1.3.0では書き出しは一覧下部、1.3.1以降は「設定」にあります。1.2.0～1.2.3には書き出しボタンがなく、PCで補助コードを使う初回移行が必要です。マニュアル10章を参照してください。

## 主な上限と注意点

| 項目 | 上限・動作 |
|---|---|
| アプリ内録音 | 最長3分 |
| 音声1件 | 約3MB |
| 録画動画1件 | 60秒以内・約5MB |
| 履歴JSON全体 | 64MB。配送先やブラウザの保存上限も別に適用 |
| 履歴形式 | `chatto-radio-archive`。音声のみはschema 1、動画入りはschema 2 |
| 履歴取り込み | 移行先オーナーのみ |
| リピート | 同じ収録1件。自分の端末だけ。開き直すとOFF |
| 動画LIVE | 実験機能。最大320×240・約2コマ／秒 |

開設や配信者設定では処理中を表示します。通信間隔の調整中は受付済みと待ち時間の目安を表示するので、そのまま待ってください。初回開設の不要な待ちを省いていますが、連続操作などでは本体の送信間隔による待ち時間が残ります。

## 確認した範囲

収録・動画・履歴移行・音声LIVE・動画LIVE・一言・権限解除・再接続・リピート切り替えを模擬環境で確認しています。ブラウザでは模擬カメラ・マイクで、別タブへの音声・映像受信、一言と応答、再接続、停止時の解放、オーナー復元、収録共有、JSONのダウンロードを自動検証しました。

利用者から、収録音声・動画の再生と、インターネットを切り離した閉域LANでの音声・動画LIVEの別端末受信の報告があります。通信経路、最大同時利用人数、長時間運用、外部回線なしの再起動後の動作までは確認できていません。TinyBoxがLIVEを中継したか、端末同士が直接通信したかも特定していません。

実際のPCカメラ・マイク、実機でのリピート再生、端末全般の互換性は未確認です。ブラウザの自動検証は模擬のHTTPS環境で行っており、index.htmlの直接起動での全機能の動作を保証するものではありません。
